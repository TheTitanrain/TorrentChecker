# История изменений

## TorrentChecker v3.0.17

Изменения с версии 3.0.15.

- Восстановлен поиск на RuTracker через публичные Atom-ленты. Логин и пароль RuTracker больше не нужны. В каждом правиле можно указать несколько разделов по их ID. Поиск охватывает недавние записи выбранных лент.
- Magnet-ссылки RuTracker можно открывать вручную или автоматически передавать в торрент-клиент, назначенный в Windows. Для Кинозала по-прежнему доступны скачивание `.torrent` и запуск клиента с параметрами командной строки.
- Настройки и история теперь хранятся в отдельных JSON-файлах. При первом запуске можно перенести правила и историю из `settings.dat`. Логины и пароли сохраняются в Диспетчере учётных данных Windows.
- Добавлена необязательная авторизация для HTTP-прокси.
- Исправлена проверка обновлений. Уведомление появляется только для версии, которая численно новее установленной.

### Установка и обновление

Распакуйте `TorrentChecker-3.0.17.zip` в отдельную папку. Для запуска нужен .NET Framework 4.8.

При обновлении закройте старую программу, сделайте резервную копию `settings.dat`, поместите файл рядом с новым `TorrentChecker.exe` и подтвердите импорт при первом запуске. Исходный `settings.dat` содержит пароли в открытом виде, поэтому храните резервную копию в защищённом месте.

Проверьте разделы RuTracker в импортированных правилах. Старый выбор «все форумы» преобразуется в раздел `486` («Зимние виды спорта»). Выполните первую проверку с отключённой автоматической отправкой. Из-за перехода на info hash некоторые раздачи могут снова появиться как новые.
