# История изменений

## TorrentChecker v4.2.1

- История раздач теперь хранится в `history.json`. Старые файлы `history-<id>.json` читаются автоматически; после успешного сохранения программа переходит на постоянное имя.
- Добавлено восстановление после прерванной записи: новая история сохраняется в `history.pending.json` перед обновлением настроек и основного файла. При загрузке выбирается согласованная версия по `historyId`, даже если основной файл повреждён. Ошибки замены и блокировка файла не уничтожают уже сохранённые данные.
- Версии приложения, сборки, файла EXE и публикации ClickOnce обновлены до 4.2.1.

### Установка и обновление

Распакуйте `TorrentChecker-4.2.1-windows.zip` в отдельную папку и запустите `TorrentChecker.exe`. Оставьте `TorrentChecker.exe.config` рядом с EXE. Для запуска нужен .NET Framework 4.8. Сумма SHA-256 архива указана в `SHA256SUMS.txt`.

При обновлении с 4.2.0 закройте программу и перенесите `settings.json` и файл истории, указанный в `historyId`. Если уже используются `history.json` и `history.pending.json`, перенесите их оба вместе с настройками. Не удаляйте промежуточный файл вручную: он может содержать единственную актуальную историю. После смены папки введите учётные данные заново.

## TorrentChecker v4.0.0

- Кнопка «Добавить» перенесена вправо от «Проверить сейчас». Список ключевых слов занимает освободившееся место.

- В белорусском интерфейсе подпись срока хранения найденных торрентов больше не перекрывает поле ввода количества дней.
- Добавлен выбор языка интерфейса в настройках программы. Доступны русский, английский, украинский, казахский и белорусский. Интерфейс переключается сразу после сохранения. По умолчанию используется язык интерфейса Windows, а для неподдерживаемых языков — русский.
- В разделе «Поведение» одна редактируемая команда управляет отправкой magnet-ссылок RuTracker и файлов Кинозала. Пустое поле использует ассоциацию Windows. Шаблон qBittorrent позволяет пропустить диалог при автоотправке.
- Подсказка объясняет, что `%ClientPath%` подставляет путь к программе Windows по умолчанию для источника. Шаблоны µTorrent Classic и qBittorrent выбираются текстовыми ссылками «Сброс».
- При обновлении `%TorrentPath%` заменяется на `%TorrentSource%`. В смешанных правилах сохранённые параметры Кинозала сразу применяются и к magnet-ссылкам, включая `/DIRECTORY`, который документирован для локальных `.torrent`. Для старых правил только с RuTracker команда остаётся пустой.

### Установка и обновление

Распакуйте `TorrentChecker-4.0.0-windows.zip` в отдельную папку и запустите `TorrentChecker.exe`. Для запуска нужен .NET Framework 4.8. При обновлении с 3.0.19 закройте программу и перенесите `settings.json` и файл истории, указанный в `historyId`. После смены папки введите учётные данные заново.

## TorrentChecker v3.0.18

- Автопроверка при запуске работает с публичными Atom-лентами RuTracker без учётных данных.
- Повторное подключение отменяет предыдущую проверку. Поздние ответы отменённой проверки больше не меняют результаты, историю и таймер и не отправляют раздачи в клиент.
- При ошибке или таймауте Regex-фильтра сохраняются прежние результаты правила. Проверка продолжается со следующего правила.
- HTTP-запросы используют отдельные заголовки и результаты. Текстовые ответы обрабатываются и без `Content-Type`. Для сохранения `.torrent` требуется `application/x-bittorrent`.
- Исправлен разбор имён в `.torrent` с кириллицей, emoji и бинарными полями. При наличии используется непустое поле `name.utf-8`.
- Срок хранения истории задаётся целым числом дней от 1. При загрузке нулевой и отрицательный сроки заменяются на 30 дней.
- Добавлен скрипт регистрации qBittorrent и µTorrent Classic как обработчиков `MAGNET` в Windows 11. Скрипт и инструкция доступны в репозитории.

### Установка и обновление

Распакуйте `TorrentChecker-3.0.18-windows.zip` в отдельную папку и запустите `TorrentChecker.exe`. Оставьте `TorrentChecker.exe.config` рядом с EXE. Для запуска нужен .NET Framework 4.8. Контрольная сумма архива указана в `SHA256SUMS.txt`.

## TorrentChecker v3.0.17

Изменения с версии 3.0.16.

- Настройки и история теперь хранятся в отдельных JSON-файлах. При первом запуске можно перенести правила и историю из `settings.dat`. Логины и пароли сохраняются в Диспетчере учётных данных Windows.
- Добавлена необязательная авторизация для HTTP-прокси.
- Исправлена проверка обновлений. Уведомление появляется только для версии, которая численно новее установленной.

### Установка и обновление

Распакуйте `TorrentChecker-3.0.17-windows.zip` в отдельную папку и запустите `TorrentChecker.exe`. Для запуска нужен .NET Framework 4.8. Контрольная сумма архива указана в `SHA256SUMS.txt`.

При обновлении закройте старую программу, сделайте резервную копию `settings.dat`, поместите файл рядом с новым `TorrentChecker.exe` и подтвердите импорт при первом запуске. Исходный `settings.dat` содержит пароли в открытом виде, поэтому храните резервную копию в защищённом месте.

Если обновляетесь с 3.0.15 или более ранней версии, проверьте разделы RuTracker в импортированных правилах. Начиная с 3.0.16 RuTracker использует публичные Atom-ленты и magnet-ссылки. Старый выбор «все форумы» преобразуется в раздел `486` («Зимние виды спорта»). Выполните первую проверку с отключённой автоматической отправкой. Из-за перехода на info hash некоторые раздачи могут снова появиться как новые.
